# Metaheuristic Optimization Algorithms

A collection of Python implementations of
optimization algorithms, including evolutionary
computation, swarm intelligence, and
combinatorial optimization.

## Algorithms

| Category | Algorithms |
|---|---|
| Single-Objective | GA, PSO + DE |
| Multi-Objective | NSGA-II, MOPSO + MODE |
| Combinatorial | GVNS, Nagata TSP |
| Dynamic Programming | DP Knapsack |

## Tech Stack
- Python
- Evolutionary Computation
- Swarm Intelligence
- Combinatorial Optimization

## Project Goals
- Study optimization algorithms
- Implement different optimization strategies
- Analyze algorithm performance
